# 우리 가계부

초대와 승인을 통해 원하는 사람과 함께 사용하는 Flutter 가계부 앱입니다.

## 현재 구현

- 이번 달 수입·지출·잔액 요약
- 이메일 회원가입·로그인
- 로그인 상태 유지
- 사용자별 개인 가계부 생성
- Firestore 거래 실시간 저장·불러오기
- 최근 거래와 전체 거래 목록
- 수입·지출 직접 입력
- 거래 날짜 직접 선택
- 거래 분류 선택
- 월별·날짜별 거래 목록
- 월별 수입·지출 분류 통계
- 전월 대비 증감률
- 사용자 분류 추가·삭제 및 Firebase 저장
- 초대·승인 및 공동 가계부 실시간 동기화
- 개인·공동 가계부 전환
- 기존 개인 내역을 공동 가계부로 가져오기
- Android 결제 문자와 은행·카드 Push 수신
- 앱이 닫혀 있어도 결제 확인 알림 표시
- 알림을 눌러 거래 확인 화면 열기
- 여러 결제 문자를 순서대로 대기
- 자동등록 알림함 전체 목록 및 여러 건 제외
- 미저장 문자 개수를 알림에 표시
- 날짜·사용처·금액·분류·결제수단·할부개월 자동 분석
- 승인 취소·환불 감지 및 순지출 자동 반영
- 자동인식 신뢰도 표시와 같은 알림 중복 저장 방지
- 알림에 날짜가 없을 때 실제 수신 시각 사용
- 저장하기 전까지 알림과 거래 초안 유지
- 분석 결과 확인 후 저장
- 같은 사용처의 수정 결과를 무료로 학습
- 삭제 내역 휴지통 보관·복원·완전 삭제
- 엑셀용 CSV 백업 복사
- 실제 CSV 파일 내보내기·다시 가져오기
- 날짜 범위를 지정한 CSV 내보내기와 중복 가져오기 방지
- 설정과 전체 내역을 보관하는 JSON 전체 백업·복원
- 사용처·분류·메모 검색과 수입·지출·분류·금액 상세 필터
- 월 예산 및 분류별 예산 설정, 70%·90%·100% 단계 알림
- 저축 목표, 하루 권장 지출, 월말 예상 지출을 보여주는 금융 코치
- 월세·보험·구독료 등의 매주·매월·매년 반복 내역
- 반복 종료일, 금액 변동, 등록 전 확인 설정
- 자동으로 읽을 은행·카드 Push 앱 선택
- 4자리 PIN과 지문·생체인증 앱 잠금(20초 이상 다른 앱 사용 후 다시 잠금)
- PIN 5회 실패 시 30초 잠금
- 핑크·라벤더·민트·나이트 테마 선택
- 이번 달 지출과 남은 예산을 표시하는 Android 홈 화면 위젯
- 내역 목록·달력 보기 전환과 날짜별 거래 확인
- 공동 가계부 이름·색상 설정과 이달의 1/2 정산 추천
- 공동 가계부 상대방의 새 내역을 앱 안에서 바로 알림
- 첫 실행에서 주요 기능을 알려주는 3단계 시작 안내
- Firebase 연결 상태(동기화·저장 중·오프라인) 표시
- 블러시 핑크·라벤더·크림 기반 파스텔 디자인
- 화면 전체 장식 배경과 플로팅 하단 메뉴
- 수입·지출별 색상 카드와 그라데이션 주요 버튼
- 작은 화면에서도 사용할 수 있는 반응형 스크롤 화면

## 실행

```powershell
flutter run
```

Android 네이티브 코드를 수정한 뒤에는 Hot Reload가 아니라 앱을 완전히
중지하고 다시 실행해야 합니다.

## 생활 설정 사용법

홈 오른쪽 위의 조절 아이콘 또는 `함께 쓰기` 탭의 `생활 설정` 버튼에서
다음 항목을 한 번에 관리합니다.

- 테마 색상
- 월 예산
- 반복 내역
- 자동인식할 은행·카드 앱
- 4자리 PIN 잠금
- CSV 파일 내보내기·가져오기
- 홈 화면 위젯 안내
- 분류별 예산과 월 저축 목표
- 전체 JSON 백업·복원

반복 내역은 지정한 날짜가 된 뒤 앱을 열면 한 번만 추가됩니다. 매주,
매월, 매년 주기를 지원하며 종료일과 등록 전 확인 여부를 설정할 수
있습니다. 앱을 오랫동안 열지 않은 동안의 내역은 다음 실행 때 확인합니다.

자동인식 앱 목록은 은행·카드 Push 알림을 한 번 받은 후 표시됩니다.
목록에서 체크한 앱의 Push만 읽으며 SMS 자동인식은 별도로 계속
동작합니다.

CSV 가져오기는 앱에서 내보낸 파일을 지원하며 결제수단·할부·환불 정보도
함께 보관합니다. 이미 가져온 같은 내역은 자동으로 건너뜁니다. 전체 JSON
백업은 내역과 생활 설정을 함께 옮길 때 사용합니다. Android 파일 선택기에
Google Drive가 보이면 별도 유료 API 없이 Drive 위치에 저장할 수 있습니다.

Android 홈 화면을 길게 누른 뒤 `위젯 > 우리 가계부`를 선택하면 이번
달 지출과 남은 예산을 볼 수 있습니다. 위젯 숫자는 앱을 열어 데이터가
동기화될 때 갱신됩니다.

## 가상 문자 테스트

Android Emulator의 `Extended controls > Phone`에서 아래 형식의 SMS를
전송합니다.

```text
[우리카드] 07/30 14:20 스타벅스 5,800원 승인
```

문자가 도착하면 앱에 거래 확인 화면이 자동으로 표시됩니다.

## 무료 학습형 자동분류

문자·Push는 휴대폰에서 규칙으로 분석하며 외부 AI로 전송하지
않습니다. 자동 인식 내역의 사용처와 분류를 고쳐 저장하면 현재
가계부에 `사용처 -> 분류` 규칙을 기억합니다. 다음에 같은 사용처가
나오면 기억한 분류를 자동으로 적용합니다. Firebase Spark 요금제로
사용할 수 있으며 Cloud Functions·OpenAI API·API 키가 필요하지 않습니다.

## Firestore 규칙 배포

거래 데이터 형식 검증과 휴지통 기능을 사용하려면 규칙을 배포합니다.

```powershell
firebase deploy --project shared-budget-46538 --only firestore:rules
```

이번 3.0 업데이트는 결제수단·환불·인식 신뢰도 필드를 추가했으므로 새 APK를
사용하기 전에 위 명령을 한 번 실행해야 자동등록 저장 권한 오류가 나지 않습니다.

## 현재 무료 방식의 범위

- SMS와 Push 분석은 휴대폰 안에서 실행하므로 외부 AI 비용이 없습니다.
- 앱을 열어 둔 동안에는 공동 가계부 상대방의 새 내역을 즉시 알려줍니다.
- 앱이 완전히 닫힌 상태의 상대방 내역 Push는 FCM을 보내는 서버가 필요해 현재
  무료 로컬 방식에는 포함하지 않았습니다.
- Firebase App Check와 Crashlytics는 Firebase Console 등록 뒤 켜야 하므로 기본값으로
  강제하지 않았습니다. 준비 없이 켜면 개인 APK의 정상 접속까지 막을 수 있습니다.

## 개인 Release 서명

현재는 `android/key.properties`가 없으면 테스트용 개발 키로 APK를
만듭니다. 계속 업데이트해서 개인 휴대폰에서 사용하려면 한 번만 개인
서명키를 만드세요.

```powershell
keytool -genkeypair -v -keystore android/app/shared-budget-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias shared-budget
Copy-Item android/key.properties.example android/key.properties
```

그다음 `android/key.properties`의 비밀번호를 실제 값으로 바꾸고 빌드합니다.

```powershell
flutter build apk --release
```

`key.properties`와 `.jks` 파일은 Git에서 제외됩니다. 특히 `.jks` 파일을
잃어버리면 같은 앱으로 업데이트할 수 없으므로 별도 안전한 장소에
백업해야 합니다.
